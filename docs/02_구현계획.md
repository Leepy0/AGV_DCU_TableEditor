# 표 편집기 구현 계획

> 작업자에게: 작업 하나를 맡으면 이 문서의 "공통 규칙"과 자기 작업 절, 그리고 사양서의 해당 절을 읽는다. 앞 작업이 만든 코드는 저장소에서 직접 읽는다.

- 목표: 사양 10.1절 단계 0\~4(1차 출시)를 만들고 `v0.1.0` 을 Release 로 낸다.
- 구조: [01_설계서.md](01_설계서.md). 조각 목록이 하나뿐인 원본이고, 문법 표가 읽기·쓰기·검사·화면을 움직인다.
- 기술: C# / .NET 10 / WPF, win-x64, NuGet 패키지 0개.
- 사양: 앱 저장소(비공개)의 `docs/09_표편집기_개발사양서.md`. 읽기만. 아래 "사양 n절"은 이 문서다.
- 화면 기준: [mockup/tag.png](mockup/tag.png), [mockup/tag_add.png](mockup/tag_add.png), 값은 [mockup/mock.css](mockup/mock.css).

## 공통 규칙

| 규칙 | 내용 |
|---|---|
| 읽기 전용 | 앱 저장소·코어 저장소를 받은 폴더에는 파일 쓰기·git 쓰기 명령을 하지 않는다 |
| 쓰기 시험 | `$env:TEMP\tedit_scratch\app` 에 앱 저장소를 로컬 clone 해서 한다. clone 뒤 바로 `git remote set-url --push origin DISABLED` |
| 공개 경계 | 이 저장소의 어떤 파일에도 실제 사이트 이름, 실제 프로파일·별칭 이름, 앱 저장소 커밋 해시, 사람 이메일을 쓰지 않는다. 커밋 전에 작업 지시에 받은 금지 낱말을 찾아 0건인지 본다 |
| 시험 자료 | 저장소 안 시험은 `tests/fixtures/T900_DEMO` 만 쓴다. 실제 사이트 시험은 환경 변수 `DCU_APP_ROOT` 가 있을 때만 돌고 기대값은 명령 인자로 준다 |
| 패키지 | NuGet 패키지를 더하지 않는다. `System.*` 만 |
| 글자 | 소스·문서 UTF-8(BOM 없음). PowerShell `Set-Content`/`Out-File` 로 한글 파일을 쓰지 않는다 |
| 문서 | `.md` 의 범위 표기는 `\~` |
| 커밋 | 작업 안에서 뜻 단위로. 한글 메시지. 끝에 `Co-Authored-By: Claude Fable 5.2 <noreply@anthropic.com>`. `git add -A` 금지 |
| push | `origin master`(AGV_DCU_TableEditor)만. 강제 push 금지 |
| 화면 글 | 설명 문장·힌트 없음. 라벨·값·버튼만. 낱말 위주. 위험 동작은 팝업. 같은 줄 버튼은 같은 크기, 강조는 색 |
| 끝 보고 | 한 일, 돌린 명령과 출력 끝줄, 못 한 것, 사양과 달리 한 것 |

## 살펴볼 것

작업 시험이 놓치기 쉬운 입력. 각 줄은 괄호 안 작업의 시험에 넣는다.

1. CRLF·LF 가 섞인 파일, 마지막 줄 끝 문자가 없는 파일, 줄 끝 공백 → 왕복 바이트 동일 (작업 0)
2. 여러 줄에 걸친 문장, `TAG ( 1, …` 처럼 이름 뒤 공백, 인자 안 주석 → 원문 보존 (작업 0)
3. 모르는 매크로·인자 꼴이 구역 안에 있음 → 죽지 않고 원문 블록, R-1 경고 (작업 0·1)
4. 읽은 뒤 바깥에서 파일이 바뀜 → 조용히 덮지 않는다 (작업 2)
5. 저장 중 실패(R-3, 디스크) → 모든 파일이 저장 전 그대로 (작업 2)
6. `gcc`·`cl2000`·`git` 이 없음, 방금 만든 exe 가 막힘 → 죽지 않고 이유를 낸다 (작업 3)

## 작업 0: 읽기·쓰기 엔진

- 사양: 2.3, 2.6, 3.9, 4절 전부, 5.1\~5.5절. 수용 시험 A-1, A-2, A-12, A-13.
- 만드는 것: `TableEditor.sln`, `.gitignore`, `src/TableEditor.Engine`(`Text/`, `Grammar/`), `src/TableEditor.Cli`, `tests/TableEditor.Tests`, `tests/fixtures/T900_DEMO`.
- 정한 것:
  - `Text`: `SourceFile.Read(path)` → 조각 목록(`Piece`: 문장 / 주석 / 빈 줄 / 원문). `SourceFile.ToText()` 는 안 고친 조각의 원문 구간을 그대로 잇는다. 조각 목록과 문장은 바꾸지 않는 값이다.
  - `Statement`: 들여쓰기, 이름, 인자 목록(앞 공백 / 글자 / 뒤 공백 / 풀이 나무), 꼬리 주석, 줄 범위.
  - `Grammar/GrammarTable.cs`: 사양 4절의 163개. 한 줄 = 이름, 자리, 인자 칸(종류·범위·단위·생략·여러 개), 꼴(안쪽 공백), 태그 칸 수, ACT 금지, 머리 이름(한글), 분류, 코어 버전 범위.
  - `Grammar/FileZones.cs`(사양 5.2절), `Grammar/CoreConstants.cs`(사양 3.9절).
  - UTF-8 이 아니거나 BOM 이 있는 파일은 통째 원문·읽기 전용.
  - `T900_DEMO`: 지어낸 이름으로 만든 사이트 폴더. 문법 표의 모든 이름이 한 번 이상 나온다. 실제 사이트 파일을 베끼지 않는다.
- 명령줄: `tedit roundtrip <폴더>`, `tedit stat <폴더>`, `tedit headers <core 폴더>`. 종료 코드 0 = 통과.
- 끝 기준:
  - `dotnet build -c Release` 경고 0, `tests` 실행 파일 종료 코드 0.
  - `tedit roundtrip tests/fixtures/T900_DEMO` 통과. `T900_DEMO` 의 표 구역 안 원문 블록 0.
  - `DCU_APP_ROOT` 로: 143 사이트 폴더 `roundtrip` 통과(파일마다 SHA-256 동일), `stat` 이 사양 A-2 수와 같음, `headers <앱>/core` 163개 일치, A-12.
