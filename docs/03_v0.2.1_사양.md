## B. 새 코어 DSL 형식 지원 (코어 v0.58.0 뒤)

원칙:

| 원칙 | 내용 |
|---|---|
| 읽기 | 옛 형식·새 형식 모두 읽는다. 옛 이름은 별칭으로 남는다 |
| 기존 줄 | 원문 그대로. 자동 변환 없음 |
| 새 줄 | 코어 버전이 v0.58.0 이상일 때만 새 형식으로 쓴다. 판단은 사이트 `core/VERSION`. 미만이면 옛 형식 |
| 구현 시점 | 코어 v0.58.0 릴리스 뒤. 그 전에는 A만 |

### B1. 조건 `AND( … )`

| 항목 | 내용 |
|---|---|
| 항목 | `ON(입력)`, `OFF(입력)`, `ANY(a,b…)`(최대 2), 상태 낱말. 순서 자유. 7개까지 |
| 상태 낱말 수 | 시퀀스 1개, 태그 2개 |
| 시퀀스 제약 | 상태 낱말과 둘째 `ANY` 를 함께 못 쓴다. `PARAM_TIME` 과 상태 낱말도 함께 못 쓴다(저장 칸이 겹친다) |
| 옛 이름 | `WHEN_IF`·`WHEN_IF_IN`·`WHEN_ANY2`·`WAIT_IF*`·`WAIT_ANY2*`·`IF_X*` 는 새 줄에서 쓰지 않는다 |
| `TAG_IF` | `X_…`, `IF_…`, `AND(…)` 모두 받는다 |

받는 명령: `WHEN`, `WAIT`, `WAIT_TO`, `WAIT_STABLE`(`_TO`), `ERROR_HOLD`, `OUT_FLICKER_UNTIL_IN`(`_TO`), `TAG_IF`, `TAG_RANGE_IF`.

### B2. 상태 낱말

| 새 | 옛 |
|---|---|
| `FORWARD` | `X_FORWARD` / `IF_FORWARD` |
| `BACKWARD` | `X_BACKWARD` / `IF_BACKWARD` |

### B3. 명령 형식

| 명령 | 새 형식 | 비고 |
|---|---|---|
| 속도 | `AGV_SPEED( HIGH\|LOW\|LLOW\|MIN \| 4\~255 )` | 숫자는 m/min. `AGV_SPEED_MMIN` 은 별칭 |
| 보고 | `ACS( 종류, 번호 )` | 번호 칸: 숫자, `STATION(k)`, `STATION(k)±n`, `AGV_ID`. 태그는 `TAG_NUM±n`, `AGV_ID_MINUS(n)` 도. `ACS_SEND` 는 별칭. 태그 1칸 형식은 옛 `ACS( 종류, STATION0 )` 만 |
| 대기 제한 | `WAIT_TO( 조건, 제한, 라벨 )` | 제한 칸: 틱 숫자 또는 `PARAM_TIME( FND, TICK\|DSEC\|SEC\|MIN )`. `WAIT_TO_PARAM` 은 별칭. 제한은 타임아웃이고 넘으면 라벨로 간다 |
| 별칭 | `WAIT_PARAM_TO`, `IN_INVERTED`(= `IN_ACTIVE_HIGH`), `OUT_SET`, `NO_ACTION` | |

- A4 의 형식 칸과 맞물린다. B 뒤에는 "속도 단계 · m/min", "대기 제한 없음 · 틱 · 파라미터"가 한 명령 안의 형식이 된다.

### B4. 동작 변경 (이름표·설명에 반영)

| 대상 | 새 동작 |
|---|---|
| `HANDSHAKE` | 출력 켬 → 응답 켜짐 대기 → 출력 끔 → 다음 스텝. 응답 꺼짐 대기가 없어졌다 |
| `OUT_FLICKER_UNTIL_IN` | 모든 조건을 받는다 |
| ACS 보고 | `STANDBY` 만 정지 + 재전송. 나머지는 ACK 가 올 때까지 재전송만 |
| 정지 명령 수행 중 | 감속·정지 진행 중에 다른 태그의 정지·회전 명령은 모든 태그에서 무시. 그래서 `X_STATION_RUNNING` 은 `X_STATION` 과 같아진다 |

### B5. 검사 추가 (코어 정적 검사로 새로 컴파일 오류가 되는 것)

| 대상 | 규칙 |

| 태그 동작 | 4칸 초과 |
| 태그 표 | 시퀀스 명령이 있음 |
| `IN` 안 | `ANY2_ON` |
| `WAIT_TO` | `UNMATCHED` |
| 제한 | `0x8000` 이상 |

- 모두 오류 등급. 저장 전에 막는다. 코어 버전이 v0.58.0 미만 사이트에는 적용하지 않는다(`core/VERSION` 으로 판단).

## C. 이름표 낱말표 (사용자 확정)

화면 이름 = 원문 구문. "그대로"는 현재 이름 유지.

| 원문 | 이름표 |
|---|---|
| `WHEN( 조건, 라벨 )` 및 `WHEN_IF`·`WHEN_IF_IN`·`WHEN_ANY2`·`WHEN_ID` | WHEN |
| `WHEN_STATE( id, 값, 라벨 )` | WHEN 상태값 |
| `OTHERWISE( 라벨 )` | 그 밖 |
| `SELECT_BEGIN` / `SELECT_END` | 고르기 시작(대기) / 고르기 끝 |
| `SELECT_END_TO( 시간, 라벨 )` | 고르기 제한 |
| `GOTO( 라벨 )` | GOTO |
| `WAIT` 계열(제한 없음) | 대기 |
| `WAIT_TO` 계열 | 대기·제한 |
| `WAIT_TO_PARAM` / `PARAM_TIME` 제한 | 대기·제한(파라미터) |
| `WAIT_STABLE` / `_TO` | 유지 대기 / 유지 대기·제한 |
| `ANY` / `ANY_ON` / `ANY2_ON` | 하나라도 |
| `AND` / `IN` / `IF_IN` / `IF_X*` | 모두 |
| `X_` 상태 조건 전체("확장") | 차량 상태 |
| `X_NOT` | NOT |
| `NO_IN` / `X_ALWAYS` | 조건 없음 |
| `ON` / `OFF`(입력 조건) | 켜짐 / 꺼짐 |
| `X_FORWARD` / `X_BACKWARD` | 전진 중 / 후진 중 |
| `X_FORBACK_MODE` | 전후진 모드 |
| `X_LOW_BATTERY` | 저전압 |
| `X_ID` | 호기 범위 |
| `X_STATION` | 스테이션 범위 |
| `X_STATION_RUNNING` | 스테이션 범위(별칭) |
| `X_STATION_MOD` / `DIV` | 스테이션 나머지 / 스테이션 몫 |
| `X_TAG_NUM` | 태그 번호 = 식 |
| `X_PARAM`(`_EQ`) / `GE` / `LE` | 파라미터 = / ≥ / ≤ |
| `X_CROSS_IN` / `X_CROSS_IN_ON` | 교통제어 진입 요청 중 / 교통제어 진입 대기 중 |
| `X_CROSS_OUT` / `X_CROSS_OUT_ON` | 교통제어 진출 요청 중 / 교통제어 진출 대기 중 |
| `X_ERR_EQ` | 오류 번호 = |
| `X_KEY` / `KEY` | 키 눌림 |
| `STATION( k )`(값) | 스테이션[k] |
| `ACS_STATION( 칸, 값, 길이 )` | 스테이션 넣기 |
| `STATION_RESET` | 스테이션 초기화 |
| `END_STOP` / `END_RESTART` | 끝(재출발 없음) / 끝·재출발 |
| `ERROR_HOLD` | 오류 표시·조건 대기 |
| `HANDSHAKE` | 출력·응답 왕복 |
| `OUT_FLICKER_UNTIL_IN` / `_TO` | 점멸 / 점멸·제한 |
| `AGV_SPEED` / `AGV_SPEED_MMIN` | 속도(단계·m/min) |
| `ACS` / `ACS_SEND` | 보고 |
| `L( 라벨 )` / `SEQ_LABELS` | 라벨 / 라벨 목록 |
| `SEQ_BEGIN` / `SEQ_START` | 시퀀스 표 / 정지·시퀀스 |
| `SEQ_MAP` | 시퀀스 연결 |
| `UNMATCHED( t )` | 불일치 시간만 |
| `IN_ACTIVE_HIGH` / `IN_INVERTED` | 반대 극성 입력 |
| `ANY_PROFILE` | 모든 프로파일 |
| `AGV_ID_MINUS( n )` | 호기 − n |
| `CALL( n )` | 사용자 함수 |
| `FL` / `SL` | FL(전진 정지 거리) / SL(정지 거리) |
| `OBS_ON` / `OBS_OFF` / `OBS_OFF_AUTO` | 장애물 감지 켬 / 끔 / 자동 끔 (v0.2.0 에서 반영됨) |

- 구현: `Grammar/GrammarTable.cs` 의 머리 이름(`head`) 열을 위 표대로 바꾼다. 같은 이름표를 가진 줄이 여럿(WHEN 계열)이면 A4 의 `Family` 로 하나로 보인다.
- `AGV_MOVE` 의 "이동"은 그대로.
- B 항목(`AND`, `ANY`, `KEY`, `AGV_ID_MINUS`, `IN_INVERTED`, `PARAM_TIME`, 새 상태 낱말)은 B 구현 때 문법 표에 줄이 생긴 뒤 이 표를 적용한다.
- 문법 표 이름표를 바꾸면 selftest·시험이 기대하는 글(예: `SelfTest.cs:404`)도 같이 바꾼다.
- 공개 코어 헤더에 없는 설명(범위·제약)은 이름표에 넣지 않는다.
